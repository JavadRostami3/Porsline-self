Here are the detailed requirements. Please provide a complete technical blueprint, including Tech Stack recommendations, Database Schema, API endpoints, Frontend architecture, and the actual code structure to build this.

### 1. Core Architecture & Workflow
*   **User App Flow:** 
    1. Welcome/Intro screen explaining the research purpose.
    2. Demographics Form (اطلاعات فردی).
    3. Sequential Survey Steps: Questionnaires 1 through 7 presented one by one. The user cannot proceed to the next survey without completing the current one.
    4. Thank You / Completion screen.
*   **Admin Panel:**
    1. Secure authentication.
    2. Dashboard showing total participants, completion rates, and aggregate demographic data (charts/graphs).
    3. Individual Results View: Ability to see the exact answers of a specific participant.
    4. Export functionality (CSV/Excel) for SPSS or further statistical analysis.

### 2. Frontend Requirements
*   Framework: React (Next.js preferred) or Vue.js.
*   Styling: Tailwind CSS with complete RTL (Right-to-Left) support and a responsive, mobile-first design (since most users will use phones).
*   State Management: To hold answers across the multi-step form before submitting the final payload.
*   UI Components: Clean typography, progress bars (to show survey progress), and user-friendly radio buttons/Likert scales for answering.

### 3. Backend & API Requirements
*   Framework: Node.js (Express/NestJS) or Python (Django/FastAPI).
*   RESTful API design.
*   Endpoints needed: 
    *   `POST /api/submissions` (to save the final survey data)
    *   `GET /api/admin/stats` (aggregate data)
    *   `GET /api/admin/submissions` (list of all users)
    *   `GET /api/admin/submissions/:id` (individual answers)

### 4. Database Schema
*   Database: PostgreSQL (preferred for relational data and analytics) or MongoDB.
*   Create tables/collections that efficiently link the Demographics to the 7 specific Questionnaires.
